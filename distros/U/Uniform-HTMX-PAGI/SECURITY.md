# Security Policy

## Supported Versions

Security updates are applied to the active major releases of `Uniform::HTMX::PAGI`[cite: 5].

Version 1.02

---

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it privately:

* **Email Contact:** Joshua S. Day `<HAX@cpan.org>`[cite: 6, 7]
* **GitHub Repository:** [haxmeister/perl-Uniform-HTMX-PAGI](https://github.com/haxmeister/perl-Uniform-HTMX-PAGI)[cite: 7]

Please include:
* A description of the vulnerability and potential impact.
* A minimal reproduction script or PAGI environment payload.
* Suggested fix (if available).
