# Security Policy

## Supported Versions

Security updates are applied to the active major release of `Uniform::HTMX::Mojolicious`.

Version 1.02
---

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it privately:

* **Email Contact:** Joshua S. Day `<HAX@cpan.org>`
* **GitHub Repository:** [haxmeister/perl-Uniform-HTMX-Mojolicious](https://github.com/haxmeister/perl-Uniform-HTMX-Mojolicious)

Please include:
* A description of the vulnerability and potential impact.
* A minimal reproduction script or controller test case.
* Suggested fix (if available).
