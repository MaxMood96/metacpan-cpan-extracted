## Supported Versions

Security updates are applied to active major releases of `Uniform::Upload`[cite: 8].

Version 0.02

## Reporting a Vulnerability

If you discover a security vulnerability (such as path traversal, buffer safety issues, or arbitrary file write risks), please report it privately:

* **Email Contact:** Joshua S. Day `<HAX@cpan.org>`[cite: 10]
* **GitHub Issues:** [haxmeister/perl-Uniform-Upload](https://github.com/haxmeister/perl-Uniform-Upload)[cite: 10]

Please include a minimal test script reproducing the vulnerability.
