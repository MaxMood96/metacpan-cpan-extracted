# Historical Benchmark Experiments

These files are preserved research artifacts from earlier Linux::Event
optimization phases. They are useful for reproducing old experiments, but they
are not the supported benchmark interface for the current reactor.

Use `../run-reactor-comparison.pl` for the permanent current comparison and
`../run-callback-ceiling.pl` for callback/I/O decomposition.

Phase names inside this directory intentionally remain unchanged because they
identify the exact historical experiment being reproduced.
