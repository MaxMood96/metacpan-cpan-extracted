# Security Policy

## Supported releases

Security fixes are made against the latest stable Linux::Event release. Users
should upgrade to the newest release before reporting an issue that may already
have been corrected.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to Joshua S. Day at
<hax@cpan.org>. Include the affected version, a concise description, and a
minimal reproducer when possible. Please do not open a public issue until the
report has been assessed and coordinated disclosure is appropriate.
